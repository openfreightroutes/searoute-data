# searoute-data

The Eurostat maritime network (as shipped in searoute-ts 2.3.1) at 100, 50 and 20 km resolution, stored as gzipped JSON and packaged for Go and npm.

The network data is derived from Eurostat searoute (EUPL-1.2, https://github.com/eurostat/searoute) and port data from marchah/sea-ports (MIT). See `NOTICE` and `LICENSES/EUPL-1.2.txt`.
